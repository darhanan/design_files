# Design Files

Хранилище HTML-дизайнов с превью и категориями: **https://darhanan.github.io/design_files/**

- **Загрузить** — кнопка или перетащить `.html` в окно. Категория определяется автоматически по названию файла, заголовку, названиям экранов и тексту; поменять — через «⋯» на карточке.
- Повторная загрузка файла с тем же именем обновляет дизайн (категория, выбранная вручную, сохраняется).
- Смотреть может любой по ссылке. Для загрузки нужен GitHub-токен с правом записи в этот репозиторий (вводится один раз в ⚙︎ Настройки).

## Как устроено

Статичный сайт на GitHub Pages, без сервера. Файлы лежат в `designs/`, список — в `designs.json`, категории и ключевые слова — в `categories.json` (их можно править в настройках сайта). Сайт пишет в репозиторий через GitHub API одним коммитом на загрузку.

## Безопасность

Токен хранится в `localStorage` сайта. Поэтому дизайны всегда открываются в sandbox-iframe без доступа к этому хранилищу: и в просмотрщике, и через `view.html` («открыть в новой вкладке»). Не открывайте файлы из `designs/` напрямую, если в этом браузере сохранён токен. Ещё одна причина держать на `darhanan.github.io` только этот сайт: другие Pages-сайты на том же домене делят с ним `localStorage`.
