# Design Files

Хранилище HTML-дизайнов с превью и категориями: **https://darhanan.github.io/design_files/**

- **Загрузить** — кнопка или перетащить `.html` в окно. Категория определяется автоматически по названию файла, заголовку, названиям экранов и тексту; поменять — через «⋯» на карточке.
- Повторная загрузка файла с тем же именем обновляет дизайн (категория, выбранная вручную, сохраняется).
- Перед сохранением открывается окно: превью, название и категория, найденная автоматически. Если категория не подходит, выберите другую в списке.
- Смотреть и загружать может любой, у кого есть ссылка. При первой загрузке сайт спросит имя: оно видно на карточках. Аккаунт GitHub и пароль не нужны.

## Как устроено

Статичный сайт на GitHub Pages, без сервера. Файлы лежат в `designs/`, список — в `designs.json`, категории и ключевые слова — в `categories.json` (их можно править в настройках сайта). Сайт пишет в репозиторий одним коммитом на загрузку через маленький прокси на Cloudflare Workers (`worker/`). Прокси хранит GitHub-ключ и пропускает только запросы с адресов сайта и только к этому репозиторию, без force-push. Адрес прокси задан в `js/config.js` (`API`). Сайты, с которых разрешена загрузка, перечислены в `worker/wrangler.toml` (`ORIGINS`): сейчас это GitHub Pages и https://designfiles-dun.vercel.app. Новый адрес сайта нужно добавить туда и выполнить `npx wrangler deploy`.

### Развернуть прокси

```
cd worker
npx wrangler login
npx wrangler deploy
npx wrangler secret put GITHUB_TOKEN    # fine-grained токен: только этот репозиторий, Contents — Read and write
```

## Безопасность

Пароля нет, поэтому загружать, переименовывать и удалять дизайны может любой, кто открыл сайт. Проверка адреса сайта защищает только от чужих сайтов в браузере, а не от прямых запросов. Переписать историю нельзя: всё удалённое или испорченное восстанавливается из git. Если понадобится закрыть загрузку, верните проверку пароля в `worker/index.js`.

Дизайны открываются в sandbox-iframe и через `view.html` («открыть в новой вкладке»), а не напрямую. Так их скрипты не работают от имени сайта.
