# Design Files

Хранилище HTML-дизайнов с превью и категориями: **https://darhanan.github.io/design_files/**

- **Загрузить** — кнопка или перетащить `.html` в окно. Категория определяется автоматически по названию файла, заголовку, названиям экранов и тексту; поменять — через «⋯» на карточке.
- Повторная загрузка файла с тем же именем обновляет дизайн (категория, выбранная вручную, сохраняется).
- Перед сохранением открывается окно: превью, название и категория, найденная автоматически. Если категория не подходит, выберите другую в списке.
- Смотреть может любой по ссылке. Для загрузки нужен только пароль команды: его спросят один раз при первой загрузке. Аккаунт GitHub дизайнерам не нужен.

## Как устроено

Статичный сайт на GitHub Pages, без сервера. Файлы лежат в `designs/`, список — в `designs.json`, категории и ключевые слова — в `categories.json` (их можно править в настройках сайта). Сайт пишет в репозиторий одним коммитом на загрузку через маленький прокси на Cloudflare Workers (`worker/`). Прокси хранит GitHub-ключ, проверяет пароль команды и пропускает только запросы к этому репозиторию, без force-push. Адрес прокси задан в `js/config.js` (`API`).

### Развернуть прокси

```
cd worker
npx wrangler login
npx wrangler deploy
npx wrangler secret put GITHUB_TOKEN    # fine-grained токен: только этот репозиторий, Contents — Read and write
npx wrangler secret put TEAM_PASSWORD   # пароль, который вы раздадите команде
```

Сменить пароль команды — снова `npx wrangler secret put TEAM_PASSWORD`; у всех он спросится заново при следующей загрузке.

## Безопасность

Пароль команды хранится в `localStorage` сайта. Поэтому дизайны всегда открываются в sandbox-iframe без доступа к этому хранилищу: и в просмотрщике, и через `view.html` («открыть в новой вкладке»). Не открывайте файлы из `designs/` напрямую, если в этом браузере сохранён пароль. Другие Pages-сайты на `darhanan.github.io` делят с этим сайтом `localStorage`. Даже с паролем можно только добавлять и менять файлы в этом репозитории, а вся история остаётся в git.
